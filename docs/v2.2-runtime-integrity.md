# NetSniper v2.2 Runtime Integrity

NetSniper v2.2 is a compatibility-preserving reliability release. It fixes every confirmed finding from the v2.1.1 comprehensive audit without changing the downstream telemetry schema identifiers consumed by DeltaAegis.

## Runtime boundaries

- Headless invocations use private `.runtime/<token>` workspaces.
- Discovery retries once from clean state and every emitted host must belong to the exact authorized RFC1918 CIDR.
- Bundles are built under `.bundle-staging` and published into `runs/` with one atomic directory rename only after quality and integrity finalization.
- Unsuccessful optional OS or UDP evidence is removed before analysis and cannot be published.
- Accurate-profile duration and budget accounting covers TCP, OS, and UDP work.
- Greenbone credentials are provided through a mode-0600 temporary gvm-tools configuration file rather than process arguments.

## Compatibility boundary

The release preserves `netsniper-run-v3`, `netsniper-capability-manifest-v1`, `netsniper-host-classification-v2`, `netsniper-classifier-v2`, and the existing v2 taxonomy/evidence profile contracts. A fresh runtime bundle must be accepted by the exact DeltaAegis candidate, and a tampered bundle must be rejected, before the branch may be pushed.
