# NetSniper v2.1 DeltaAegis Evidence Enrichment

This change enriches the existing `netsniper-classification-v1` compatibility
projection. It does not introduce a new bundle artifact or require a DeltaAegis
database migration.

The additive `deltaaegis_context` includes identity quality, family/platform/
role decisions, evidence IDs by axis, contradictions, secondary candidates,
uncertainty reasons, explanations, collection completeness, observed network
roles, an operator disposition, and a stable semantic fingerprint.

The fingerprint excludes timestamps and raw observation values so repeated
scans with the same interpretation produce the same fingerprint.

Existing classification fields, manifest schemas, taxonomy, evidence weights,
scan profiles, and the frozen deterministic corpus remain unchanged.
