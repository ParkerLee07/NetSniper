# NetSniper v2.1 Empirical Evidence Calibration

This stage installs measurement-only attribution and characterization tooling. It does not change taxonomy, scan profiles, contracts, the frozen deterministic corpus, or evidence weights.

Use:

```bash
python3 tools/v2_1_calibration_report.py --input /path/to/run --labels /path/to/labels.json --output-json /tmp/report.json --output-markdown /tmp/report.md
```

The report records decisions, confidence, evidence IDs, recoverable declared contributions, contradictions, uncertainty reasons, secondary candidates, optional labeled outcomes, and readiness thresholds. Reports never mutate evidence profiles.
